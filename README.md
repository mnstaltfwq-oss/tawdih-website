# موقع توضيح المعرفة لخدمات الأعمال

موقع ثابت مبني بـ HTML وCSS وJavaScript عادي، باللغة العربية وباتجاه RTL، وجاهز للنشر على GitHub Pages.

## التشغيل محلياً

افتح `index.html` مباشرة في المتصفح، أو استخدم خادماً محلياً ثابتاً أثناء التطوير.

## الملفات

- `index.html` — الصفحة الرئيسية.
- `assets/css/style.css` — الهوية المرئية والتجاوب؛ متغيرات الألوان والخطوط في بداية الملف.
- `assets/js/main.js` — قائمة الجوال وروابط طلب الخدمة عبر واتساب.

روابط الصفحات التالية موضوعة في التنقل (`about.html` و`services.html` و`contact.html`) تمهيداً لإنشائها في الخطوة التالية. يمكن إعادة استخدام بنية الهيدر والفوتر والملفات المشتركة نفسها في الصفحات الجديدة.

## النشر على GitHub Pages

من إعدادات المستودع، اختر فرع النشر ومجلد الجذر؛ ملف `index.html` موجود في جذر المشروع، وجميع مسارات الأصول نسبية.
