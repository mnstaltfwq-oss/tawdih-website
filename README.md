# موقع توضيح المعرفة لخدمات الأعمال

موقع ثابت (HTML/CSS/JS) بالعربية RTL، جاهز للنشر على GitHub Pages.

## التشغيل والنشر
1. Settings ← Pages ← Source: Deploy from a branch ← Branch: main / (root).
2. يظهر الموقع على: https://mnstaltfwq-oss.github.io/tawdih-website/
3. للنطاق الخاص (مثل tawdih.sa): أضف النطاق في Pages ثم سجلات DNS لدى مزود النطاق.

## إضافة خدمة جديدة
1. أضف عنصرًا في قائمة `SERVICES` داخل `data.py` (الحقول مطابقة لـ `services.json`).
2. لا تكتب شروطًا أو مستندات من التخمين: اترك الحقل `None` حتى تتوثق من المصدر الرسمي.
3. شغّل `python3 build.py` لتوليد الصفحات، ثم ارفع الملفات المتغيرة.

## قبل الإطلاق
- أضف البريد الرسمي في `CONFIG["email"]` داخل `data.py`.
- راجع الصفحات القانونية (مسودات) مع مستشار قانوني.
- تأكد من أسماء الجهات الرسمية، ولا تستخدم شعاراتها دون إذن.
